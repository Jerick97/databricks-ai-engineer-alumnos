# Requisitos y riesgos

| Requisito | Riesgo | Evidencia necesaria |
|---|---|---|
| Conversar sin aprobación previa | Bloqueo artificial del chat | Pregunta real sobre changeset unreviewed |
| Contexto de seguimiento | «Ese punto» resuelto en familia anterior | Transición de familia/artículo y aclaración ambigua |
| Antes/después fiel | Solo se recuperó una versión | Citas de ambas o respuesta limitada explícita |
| Implicancias diferenciadas | Inferencia se convierte en obligación | Claim kind y supuestos junto a evidencia |
| Conflictos visibles | Tabla/archivo no coinciden | Snapshot/acto modificatorio y limitación |
| Herramientas permitidas | Documento modifica permisos | Negativas SK08 más servidor, no solo prompt |
| Error honesto | Degradación presentada como pipeline completo | Estado, etapas ejecutadas y límites visibles |

Salida Answer conforme SK01 y traza de rutas. No aprobar impactos, modificar normas, publicar ni enviar mensajes a terceros.
