# Skills SBS Radar · SK00–SK12

Las 13 skills del agente, visibles desde la raíz del repositorio. Cada carpeta incluye `SKILL.md` y sus referencias/evaluaciones disponibles.

Estas son copias de distribución. La fuente de trabajo se conserva en [sbs-radar-workspace/skills](../sbs-radar-workspace/skills). Ejecuta los procedimientos con `sbs-radar-workspace` como contexto del proyecto. Las skills son provisionales: publicar sus archivos no certifica todos los componentes ni sustituye sus pruebas.
