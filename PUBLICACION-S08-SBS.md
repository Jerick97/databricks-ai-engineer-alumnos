# Entrega S08 y SBS Radar

Abre `MATERIAL-HOY.html` después de clonar o descargar el repositorio. GitHub muestra los HTML como código; para la presentación interactiva abre el archivo local o sirve esta carpeta con `python3 -m http.server 8080`.

- `s08-deployment/`: slides (incluido glosario), notebooks, código del agente Neptuno, App y scripts de despliegue.
- `sbs-radar-workspace/`: código del piloto, corpus, notebooks, SK00–SK12, framework, guía E2E, réplica explicada y videos.
- `.archify/`: diagramas de ingesta y consulta.
- [SBS Radar independiente](https://github.com/manuelarguelles/sbs-radar-e2e): código y diseño IaC; IaC completo pendiente.
- [Genie IaC público](https://github.com/manuelarguelles/ianbal-genie-iac): ejemplo independiente implementado.

Los recursos Databricks enlazados requieren acceso propio. Las credenciales y autorizaciones temporales no se distribuyen. Foquito no incluye la clave local del docente; las explicaciones hover son consultables. Los pesos de modelos se obtienen por los procedimientos del proyecto, no están incluidos. Publicación del material no equivale a nuevo despliegue validado.
